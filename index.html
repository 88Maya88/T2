See which workforce factors point toward attrition

Enter an employee's details and AttriLens returns a predicted attrition outcome from the study's ensemble model, along with the factors that shaped that prediction.

Start a prediction See how it works

How it works

  1. Enter employee details

    Fill in the survey form with the workplace information the model was trained on.

  2. Get a prediction

    The ensemble model returns a predicted outcome and, where available, a probability.

  3. Read the explanation

    SHAP shows which features contributed most to this one prediction.

Good to know

  • Explanations describe what the model weighed. They do not show what caused someone to leave.
  • AttriLens is a prototype interface for the study's validated framework. It is not a separate model.
  • It does not measure or predict migration readiness. That topic is reserved for future research.
